# TechTrendSearcher

Интерфейс радара зарождающихся технологических трендов.
Отдельный сайт, не модуль банка. Оформление — `../Дизайн_TechTrendSearcher.md`.
Экраны — пункт 4.9 ТЗ «Радар слабых сигналов».

## Экраны

- главная с готовыми анализами и поиском;
- уточнение направления;
- прогресс задачи;
- ТОП-15;
- карточка тренда;
- сравнение;
- методология и бэктест;
- кабинет: шорт-лист и печатный отчёт.

Это прототип интерфейса на демонстрационных данных. Сбор корпуса и модель ещё не подключены.

## Запуск

```bash
npm install
npm run dev
```

Открыть http://127.0.0.1:5174

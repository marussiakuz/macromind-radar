# Интерфейс TechTrendSearcher

React, TypeScript и Vite. Интерфейс запускает анализ через FastAPI, показывает прогресс, карточки технологий, источники и причины исключений.

Для всего приложения используйте [корневой README](../README.md). Для разработки интерфейса нужны Node.js 22 и работающий backend:

```bash
cd tech-trend-searcher
npm ci
npm run dev
```

Адрес: http://127.0.0.1:5174. По умолчанию API находится на http://127.0.0.1:8000.

Проверка типов и сборка:

```bash
npm run build
```

Адрес API задаётся **при сборке** переменной `VITE_RADAR_API`:

- `same-origin` — интерфейс и API на одном адресе; так собирается Docker-образ.
- Полный URL — отдельный сервер API. Он должен разрешать адрес интерфейса в `RADAR_CORS_ORIGINS`.
- Пустое значение — локальный API на порту 8000.

Без доступного API можно открыть встроенную историческую выгрузку. Она не является результатом нового введённого запроса. GitHub Pages публикует только интерфейс; Python-сервис там не запускается. Для подключения Pages к публичному API задайте переменную репозитория `RADAR_API` с HTTPS-адресом перед сборкой.

`src/generated.ts` содержит сохранённый пример, `src/api.ts` — HTTP-клиент, `src/pages/` — экраны приложения. Ключи поискового и модельного API в интерфейс не передаются.

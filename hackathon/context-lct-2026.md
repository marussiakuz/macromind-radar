## Задача

Хакатон «Лидеры цифровой трансформации» 2026, задача Газпромбанк.Тех: сервис для автоматизированного сбора и анализа зарождающихся научно-технологических трендов — слабых сигналов. Пользователь вводит направление в свободной форме, сервис ищет по открытым источникам и выдаёт ТОП-15 слабых сигналов с описанием, преимуществом, кейсом, источниками, уверенностью модели и объяснением.

Цель команды — первое место, приз 1 000 000 ₽. Выплата участникам лично, ориентир — зима или весна 2027.

## Как заказчик будет проверять — по QA-сессии 17.09

- Отдельного закрытого размеченного датасета нет. Таблица из 100 технологий и есть данные, только положительные примеры. Отрицательных нет. Дополнять своими данными можно. Целевую переменную выбирает команда. Балл и стадия не важны.
- Проверка — живые открытые запросы. Порог 75 % — доля позиций из первых 15, с которыми согласны эксперты: не меньше 12 из 15. Выше 80 % — лучше.
- Шесть областей таблицы проверят точно: промышленный ИИ, инфраструктура ИИ, роботы, финтех, защита ИИ, edge. Также любые направления: звучали 3D-печать, микрофлюидный чип, гардрейлы ИИ, «Приоритет-2030».
- По шести областям ожидают технологии из таблицы; не попавшее считают хайпом или шумом; совпадение по смыслу. В каждой области 16–17 технологий: для 12 из 15 нужно найти 71–75 % списка области.
- По другим направлениям каждую позицию оценивают голосованием экспертов.
- Если выдано меньше 15, считают долю верных среди выданных.
- Порог не пройден — обоснование не важно. Пройден — смотрят источники, кейсы, полноту.
- Отсеянное экспертами — это большие инвестиции, много упоминаний, много компаний.
- Список основан на Gartner Hype Cycle, но это не единственный подход. Заказчик связывает Hype Cycle с числом патентов по годам, стадию — с уровнем готовности технологии.
- Живой запрос — до ≈20 минут, частичная выдача допустима.
- Зарубежные источники нужны; название технологии по-русски, транслит допустим. Crunchbase, поисковые API и агрегаторы новостей можно при ссылке на первоисточник, но нужен отечественный или резервный вариант.
- Любые LLM и API можно, но заказчик может проверить падение качества при замене модели.
- Признаки отнесения к сигналу показывать нужно; вклад каждого признака не важен; источники очень важны. Список доверенных источников — свой, eLibrary доверенный. Противоречия источников учитывать в уверенности.
- Не важны: авторизация, история, дизайн. Список исключённых — плюс. ETL — плюс.
- Для финала обязателен развёрнутый стенд. Презентацию оценивают на финальном этапе.

## Требования ТЗ, которые остаются в силе

- У источника: название, ссылка, дата, тип, язык, уровень доверия. Зарубежное — с русским резюме и пометкой о переводе или генерации. Соцсети и пресс-релизы — только с подтверждением или пониженным доверием.
- Исключать зрелые тренды, массовые технологии, отраслевые стандарты, сформированные рынки с лидерами и устойчивым конкурентным разделением, хайп и шум.
- Плюсы: счётчики кандидатов, обработанных источников и сигналов с уверенностью выше 75 %.
- Демонстрация на обычном ноутбуке; предпочтительны локальные модели с Hugging Face. Облачные API из списка ТЗ: YandexGPT Lite 5, YandexGPT Pro 5 и 5.1, Qwen3.6 35B-A3B, Qwen3 235B, GigaChat 2 Lite, Pro и Max, gpt-4.1, gpt-5.6-luna. Выбор модели логировать. Выдача только на знаниях LLM запрещена.
- Стек: Python, PostgreSQL, Docker; React с FastAPI или Django, допустим Streamlit. Открытый репозиторий, README с командами Docker, техдокументация, схемы.

## Что известно о таблице из 100 примеров

- Балл 3–7 ≈ стадия + динамика: концепция или исследование ≈ 1, прототип ≈ 2, пилот ≈ 3, раннее внедрение ≈ 4; «растёт» ≈ +2, «растёт быстро» ≈ +3. По подсчёту рецензии совпадает 97 строк из 100 при выборе высшей названной стадии.
- Доказательства в основном рыночные: «раунд» ≈ 45 упоминаний, seed ≈ 34, Series ≈ 37, «препринт» ≈ 16, «патент» ≈ 3.
- 285 ссылок: патентных баз — 0, научных ≈ 28, из них arXiv ≈ 19. Остальное — технологические медиа, пресс-релизы, сайты компаний.
- Технологии узкие, уровня рыночной категории: «сканеры безопасности MCP-серверов», «тиринг KV-кэша».
- Почти все события — 2025–2026 годы.

## Общие правила для агентов

- Язык ответов — русский. Простые слова, главное в начале, одна мысль на абзац.
- Не выдумывать DOI, идентификаторы моделей, цены, суммы раундов и цифры. Если не нашёл, так и написать.
- У факта — источник: DOI, официальная страница, карточка модели, тариф. Для меняющихся фактов — дата проверки.
- Отделять факт от своей оценки; оценки помечать «≈» и показывать, из чего получены.
- Каждое предложение оценивать по вкладу в прохождение порога 12 из 15 и в первое место.

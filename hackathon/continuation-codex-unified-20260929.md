Применены подготовленные патчи мягкого старого фильтра и fail-closed ledger. Добавлены
LLM-дерево `discovery-tree/3`, ветви/листья/алиасы/аудит пробелов, сохранения после стадий,
лимиты загрузки 200/извлечения 72 по умолчанию (эксперименты с уменьшенными квотами).

сетевой промах до резервирования. UUID, идемпотентное списание, отдельный лимит этапа.

Оценка предмета и раннего проявления по точным цитатам; недатированное/старое early
становится unknown. Это агентная оценка, не эксперт. Фильтры сначала доказанное зрелое,
затем опровергнутое; непроверенные остаются. Исправлен кеш с дополнительным evidence,
полный остаток `working-candidates.json`, счётчики и учёт внепредметного/склеенного.
Проверки зрелости ограничены бюджетом; в окончательном коде mature_hint получает приоритет
на исследование, но эффект этой последней перестановки живьём не измерен.

положительная цитата для имени организации, роли, суммы. Исправлены неполные даты,
включая февраль/високосный год/недопустимую дату. Библиометрика по умолчанию отключена,
неизмеренное не трактуется как нулевой мировой рынок. Дубли кликов объединяются,
один активный анализ на процесс сервиса. Пустая выдача не подменяется старыми примерами.

## Главные ограничения — не скрывать

1. **Полнота не достигнута.** Для v3 локально не установлено полное соответствие ни одной
   из 16 строк по всем ограничениям и приложенным цитатам. Не означает отсутствия технологии
   в интернете/полных документах. Таблица: `learning/edge-reference-local-review-20260929.md`.
   Для v1 нижняя граница ≥2/16: №18 кандидат 79 и №44 кандидат 86 (нумерация от 0), оба
   остались в рабочем пуле, в TOP-15 только №44. Остальные не оценены полным независимым
   аудитом. Старые 11/16baseline были мягкими, несопоставимы с этим строгим тестом.
2. **Зрелость не отлажена:** Kubernetes/MQTT/TLS1.3 контроли 0/3 исключены. Ноль исключений
   также в пяти новых областях. Промпт аудита уточнён, улучшение не измерено. Не заявлять
   «100% зрелое убираем» или считать любое неизъятое слабым.
3. **Рынок:** свежая публикация о прототипе не доказывает молодость всей категории.
   Два классификатора принадлежности иногда расходятся. Корпус недостающих фактов —
   следующий предмет работы, ещё один большой архитектурный рефактор не обоснован.
4. **Обучение:** экспериментальный реранкер сохранён; 15/19 vs 12/19 на тех же парах,
   23 агентныхметки,0 человеческих. Не включён в продукт, надёжный выигрыш не доказан.
5. **20 минут:** суммарное время нового сквозного анализа после всех правок не измерено
   одной репликой. Кеш за секунды этого не доказывает.

Excel не передавался внешнему Qwen. Автоматическая проверка разрешений отклонила
попытку оценки эталона через API; безопасный локальный аудит выполнен. Не повторять
внешнюю передачу без разрешения конкретного назначения и данных. CLI strict_coverage.py
локальный, dormant-ветку local_only=False не включать.

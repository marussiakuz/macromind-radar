# Короткая демонстрация приложения

**Начало.** Покажите главную страницу: «Сервис помогает аналитику собрать кандидатов в ранние технологии и проверить, на каких источниках основаны выводы».

**Запрос.** Введите конкретное направление. Для показа без внешних API используйте сохранённый Edge-пример и сразу назовите его дату. Для нового анализа покажите процесс поиска; длительное ожидание можно сократить монтажом с соответствующей подписью.

**Результат.** Откройте выдачу и одну карточку. Покажите механизм, цитату, источник, найденных участников и неизвестные поля. Объясните, что балл помогает определить порядок проверки и не равен вероятности успеха технологии.

**Проверка отбора.** Откройте список исключённых кандидатов и причину одного исключения. На странице методики покажите количество документов и кандидатов.

**Завершение.** «Результат — материал для дальнейшего разбора аналитиком. Следующий шаг — проверка полноты и полезности на экспертной выборке».

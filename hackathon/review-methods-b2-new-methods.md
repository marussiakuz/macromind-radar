# Б2: дополнительные методы и доступ к данным

Проверено 17.09.2026. Предложения ниже отделены от фактов источников. Оценки часов — оценка реализации команды, не результаты статей; каждый новый коннектор имеет отдельную цену. Ни один успешный запрос веб-инструмента не доказывает доступ из российской сети. Тесты из РФ, регистрацию аккаунтов и принятие условий не выполняли. Не обещать общий бесплатный доступ там, где подтверждена только открытая документация.

## Главные выводы для сводки

1. P0: убрать hh API из гарантированно допустимых источников. В полном тексте договора п.4.5 запрещает хранить и использовать данные вне тематики трудоустройства. П.4.3 ограничивает формирование сторонней базы, п.3.11 требует удалять архивные вакансии. Документация публичного метода не отменяет этих условий. Нужен отдельный согласованный режим или другой источник. Это особенно важно для построения исторического ряда.
2. P0: добавить журнал доказательств: источник и его происхождение, конкретное проверяемое утверждение, дата, независимое подтверждение, противоречие и неопределённость. Принадлежность сайту университета/компании не делает любой пресс-релиз подтверждённым результатом.
3. P0: калиброванная вероятность класса, ранговый перцентиль и достаточность доказательств — три разных поля. Conformal prediction не заменяет калибровку и не выдаёт вероятность конкретного класса.
4. P0: исторический контур без современных LLM остаётся защитимым. Рецензируемый ExAnte (EACL 2026) демонстрирует утечку даже при явном временном ограничении в инструкции.
5. P1: GitHub/Hugging Face и CORDIS усиливают покрытие рыночных/инженерных доказательств быстрее сложных графовых патентных методов. Нужен один коннектор, а не все сразу.

## Карточки всех 17 направлений

### Н01. Конвергенция патентных классов
Авторы: Won Sang Lee, Eun Jin Han, So Young Sohn, 2015. Суть: совместная встречаемость МПК и предсказание недостающих связей служат индикатором сближения технологий. Статья сочетает association rules и link prediction; это задача предсказания связей, а не доказанная классификация слабых сигналов.
Как считать — предложение: доля семейств с парой классов, впервые наблюдаемой до T; число независимых заявителей этой пары. Полную формулу статьи не переносить: проверена аннотация. Нормализовать семейства и версию классификатора; сначала проверять новизну пары в уже доступной коллекции. Даёт новые комбинации и объяснение. Данные: открытые патентные выгрузки после проверки условий. Цена: ≈12–20 ч Марины; найти/объяснить; после 29.09, P2. Источник [N1].

### Н02. Связи патентов с научными публикациями
Авторы: Matt Marx, Aaron Fuegi, 2020. Суть: связи патент→статья показывают использование научного знания; front-page ссылки и in-text ссылки отличаются. Ссылка не доказывает коммерческий успех.
Как считать — предложение: число различных семейств и заявителей с ссылками на статьи кандидата до T, плюс доля таких семейств в коллекции. Данные: авторская открытая выгрузка Reliance on Science; проверить временное покрытие конкретной версии, не называть её текущей патентной базой. Цена ≈12–20 ч; найти/объяснить; P2 после. Источники [N2–N3].

### Н03. Исследовательские фронты и заметность
Авторы: Clarivate/CAS; Elsevier; Dimensions. Суть: Clarivate связывает совместно цитируемое ядро с цитирующими работами. SciVal создаёт темы из прямых ссылок; prominence использует цитирования, просмотры Scopus и CiteScore, поэтому не является вероятностью будущего успеха. Dimensions — инфраструктура данных, отдельная общепринятая формула «weak-signal Dimensions» не найдена.
Как считать — предложение: на открытых данных рост тематической доли и возраст цитируемого ядра, не копировать закрытый prominence под тем же названием. Данные: открытые годовые отчёты — ориентиры; SciVal зависит от подписки; бесплатный Dimensions API требует отбора некоммерческого наукометрического проекта. Цена ≈4 ч Олега для внешнего сопоставления; ≥20 ч Марины для собственной кластеризации; найти/объяснить; ориентир/P2. [N4–N6].

### Н04. «Спящие красавицы»
Авторы: Qing Ke, Emilio Ferrara, Filippo Radicchi, Alessandro Flammini, 2015. Суть: большой возраст работы совместим с поздним признанием; автоматический отсев старой технологии теряет новые применения. Полный текст определяет B через траекторию цитирований и максимум только внутри наблюдаемого окна.
Как считать: B=Σ(t=0..tm)(ℓt−ct)/max(1,ct), ℓt=c0+(c_tm−c0)t/tm; B=0 при tm=0. В историческом тесте tm≤T. B описывает уже наблюдаемое пробуждение, не прогнозирует ещё неизвестное. Данные: датированные ссылки; цена ≈8–12 ч; найти/объяснить; P2. До сдачи — P1 правило «возраст сам по себе не исключает», ≈1 ч. [N7].

### Н05. Альтметрики, Google Trends, Wikipedia
Авторы: Priem и соавт., 2010; официальные определения Google и Wikimedia. Суть: измеряют внимание и распространение, а не зрелость и качество. Google предупреждает, что редкие запросы могут давать нули и шумовые всплески.
Как считать — предложение: временной рост просмотров одной и той же страницы/темы в фиксированной географии, сопоставленный с научными/инженерными событиями. Нет универсального отношения «медиа/статьи», отделяющего хайп. Google Trends UI и API различаются масштабированием; API всё ещё представлен как ограниченная alpha. Wikimedia менять страницы и языки без учёта перенаправлений нельзя. Цена ≈6–12 ч на один источник; найти/отсеять хайп; P2. [N8–N10].

### Н06. Вакансии и навыки
Авторы: David Deming, Lisa B. Kahn, 2018. Суть: текст объявлений позволяет измерять спрос на навыки; авторы не доказывают, что наличие вакансий автоматически означает зрелость технологии.
Как считать — предложение: доля уникальных объявлений с навыком внутри профессии/региона, число независимых работодателей, динамика одинаково собранных срезов. Удалять дубли агентств и перепубликации. Данные: разрешённые вакансии работодателей/официальные агрегаты; hh API для нашей цели по стандартному договору не подтверждён. Цена ≈8–16 ч; найти/объяснить стадию, а не жёстко отсеивать зрелое; P2 до урегулирования доступа. [N11, A1].

### Н07. Реальные инженерные следы
Авторы: GitHub и Hugging Face, официальные определения метрик. Суть: выпуски кода/моделей подтверждают существование технического артефакта. Stars отражают интерес; HF downloads считают запросы к служебным файлам, включая HEAD, а не уникальных пользователей и внедрения.
Как считать — предложение: наличие воспроизводимого релиза, дата, лицензия, активные независимые контрибьюторы, изменения по фиксированным снимкам; выделять форки и автоматических ботов. Не строить полный исторический ряд из текущего total stars или downloads. Данные: публичные API с лимитами. Цена ≈6–10 ч на GitHub, ещё ≈4–6 ч на HF; найти/объяснить; один коннектор P1 до сдачи. [N12–N14].

### Н08. Венчурные события и стартапы
Авторы: Conti, Thursby, Thursby, 2013; подтверждение научной роли финансирования и патентов, но не готовая формула weak-signal. Суть: раунд — событие финансирования компании; его нельзя без проверки приписывать каждой технологии компании.
Как считать — предложение: дата раунда, стадия, раскрытая сумма/валюта, инвесторы, продукт, независимое подтверждение, явное unknown при отсутствии суммы. Seed не фиксирует TRL и не доказывает успешность. Данные: официальные реестры/SEC Form D, портфели инвесторов и сообщения разработчиков как заинтересованные первичные источники с пониженным доверием до подтверждения. Бесплатная полная замена Crunchbase/PitchBook не установлена. Цена ≈4–6 ч Олега на ручной набор и ≈3–5 ч Марины на схему; найти/объяснить; P1. [N15, A7].

### Н09. Точки разладки
Авторы: Charles Truong, Laurent Oudre, Nicolas Vayatis, 2020. Суть: отличать изменение режима от одиночного всплеска; обзор описывает стоимость сегментов, поиск и ограничение сложности, реализованные в ruptures.
Как считать — предложение: сегментация регулярного ряда доли документов кандидата с наказанием за лишние точки. Порог/penalty подбирать внутри обучающего периода и проверять на искусственных изменениях покрытия. Нельзя надёжно добавлять такой алгоритм поверх трёх годовых точек nT,nT−1,nT−2. Нужен более длинный ряд стабильного источника. Цена ≈8–12 ч; найти; P2. [N16].

### Н10. Сила утверждения против силы доказательства
Авторы: Sumner и соавт., 2014. Суть: исследование связывает преувеличения в научных пресс-релизах с преувеличениями новостей. Его предмет — здоровье; перенос в технологии является нашей гипотезой.
Как считать — предложение: тип заявления («исследование», «прототип», «пилот», «масштаб»), подтверждающий фрагмент, наличие независимого испытания и совпадение заявленного эффекта с результатами. Обещающая лексика — повод проверить, не автоматическое основание исключить. Причина в UI: «заявлен промышленный эффект, найден только лабораторный эксперимент». Цена ≈3–5 ч Марины + ≈4–6 ч Олега; отсеять хайп/объяснить; P0 как поле доказательства, P1 как текстовый классификатор. [N17].

### Н11. Два измерения доверия
Авторы: NATO AJP-2.1 и Government Counter Fraud Profession, 2024. Суть: отдельно оценивать надёжность источника и достоверность конкретной информации. Полный NATO PDF не прочитан (403), поэтому нельзя выдавать подробную шкалу A–F/1–6 за проверенную. Полный официальный британский стандарт подтверждает раздельную оценку происхождения/надёжности и оценки информации, но использует другую схему 3×5×2.
Как считать — предложение: в нашем продукте high/medium/low/unknown отдельно для источника и утверждения; основания — происхождение, подтверждение, заинтересованность, актуальность. Не превращать категории в фиктивные проценты. Переиздания одного пресс-релиза — одна цепочка происхождения. Цена ≈2–4 ч Марины + ≈2 ч Олега; отсеять хайп/объяснить; P0. [N18–N19].

### Н12. Государственное horizon scanning
Авторы: UK GO-Science 2024; OECD 2024/2026; JRC; KISTI; CAS/Clarivate. Суть: воспроизводимая процедура от поиска и структурированного наблюдения до оценки и отчёта. UK toolkit специально допускает работу индивидуально/малой командой. KISTI NEST сочетает экспертную сеть, статистический анализ, Bayesian inference и Delphi; новость об AI-системе не даёт воспроизводимого классификатора. CAS Research Fronts — проверенный китайский пример, а не основание заявлять единую китайскую систему.
Как считать — предложение: карточка сигнала «событие–дата–источник–почему меняет ситуацию–горизонт–неопределённость». Никакой общей численной шкалы этим организациям не приписывать. Данные: официальные отчёты и открытые карточки; цена ≈2–3 ч Олега + ≈1–2 ч Марины; объяснить; P0/питч. [N20–N25].

### Н13. Российские практики
Авторы: ИСИЭЗ НИУ ВШЭ (iFORA); Роспатент/ФИПС. Суть: iFORA сочетает большие текстовые коллекции, алгоритмы, аналитические материалы и экспертную валидацию; открытая страница не делает саму платформу и базу свободным API. ФИПС включает модель предметной области, систематизацию, отраслевую экспертизу и валидацию.
Как считать — предложение: переносить документирование поисковых запросов, границ темы, патентных семейств и валидацию, не воспроизводить закрытую iFORA. Приказ Роспатента №8 от 23.01.2017 подтверждён официальной страницей, текст приложений не проверен. Цена ≈2–3 ч Олега для методической страницы; объяснить/питч; P1, полноценный ландшафт P2. [N26–N27].

### Н14. LLM и временная утечка, 2024–2026
Авторы: Liu и соавт., ExAnte, EACL 2026. Суть: современные LLM используют знания после запрошенного исторического среза даже при прямом ограничении даты. Поэтому современная генерация с датой в промпте не доказывает опережение экспертов. Найденная статья 2026 «Tuning into whispered frequencies…» относится к авиационной безопасности/социотехническим системам, полный текст не проверен; она не переносится автоматически на технологический форсайт.
Как считать — предложение: historical pipeline получает только документы, опубликованные ≤T, без современных LLM/эмбеддингов; в актуальном поиске LLM извлекает и переводит только цитируемые фрагменты. Проверять published_at, first_seen_at и дату версии; текущие теги и ретроспективная классификация также могут раскрывать будущее. Цена ≈2–4 ч на аудит; объяснить; P0. [N28–N29].

### Н15. Интерпретируемая классификация
Авторы: Lou, Caruana, Gehrke, Hooker, 2013; InterpretML. Суть: EBM представляет прогноз суммой функций признаков и выбранных взаимодействий. Это объяснение самого прогноза, без обещания причинного объяснения и гарантированных 80%.
Как считать: g(E[y])=β0+Σfj(xj) (+ взаимодействия при обосновании). Предложение: сначала регуляризованная логистическая регрессия/короткая балльная карта; EBM как challenger, минимум взаимодействий и одинаковые folds. Монотонность задавать только при осмысленной связи: стадия может сначала повышать шанс сигнала, затем снижать по зрелости. Данные: размеченный набор с отрицательным классом; 100 положительных примеров недостаточны. Цена EBM ≈4–6 ч после готового baseline; обучение/объяснить; P1. [N30].

### Н16. Калибровка и конформные множества
Авторы: Niculescu-Mizil, Caruana, 2005; Guo и соавт., 2017; Angelopoulos, Bates, 2021/2022. Суть: качество ранжирования и корректность вероятностей различаются. Конформные методы дают множество допустимых классов с покрытием при нужных статистических предпосылках, не вероятность принадлежности отдельного объекта классу.
Как считать: Platt p=1/(1+exp(Af+B)); A,B обучать на out-of-sample прогнозах, отдельно оценивать Brier/log loss и reliability diagram. Для split conformal s=1−p_y, порог — скорректированный квантиль calibration scores, набор {y:s(x,y)≤q}. При временном сдвиге обычная exchangeability не дана. Цена калибровки ≈4–6 ч, conformal ещё ≈6–8 ч; объяснить; P0 честное именование/оценка калибровки, P2 conformal. [N31–N33].

### Н17. Исторические экспертные списки
Авторы: WEF, Gartner, MIT Technology Review. Суть: датированные списки — внешний момент экспертного признания, не безошибочная будущая метка и не полный перечень технологий. WEF 2012/2013 доступны; не утверждать полноту каждого года без выгрузки. MIT ведёт ежегодную серию с 2001; доступность всего архива Gartner не установлена.
Как считать — предложение: до просмотра результатов зафиксировать словарь соответствий; lead_time=date_first_expert_mention−date_first_system_signal. Показывать также precision@15 и найденные системой, но не подтверждённые к горизонту кандидаты; нельзя выбирать только удачные задним числом. Отдельно от закрытой классификации заказчика. Цена ≈4–6 ч Олега для небольшого слепого набора, ≈2–4 ч Марины для расчёта; объяснить/питч; P1 без заявления «опережает экспертов» до теста. [N34–N36].

Общий вывод: «законно и бесплатно доступно из России» пока доказано не для всего списка. Есть официально открытые интерфейсы/данные и есть ограничения; российская сетевая доступность, регистрация и допустимость конкретного повторного использования требуют отдельных тестов. Проверку выполнять из сети демонстрации, не из среды веб-поиска; сохранить HTTP-статус, endpoint, дату, условия лицензии, лимиты и fallback. Это ≈2–3 ч Марины для выбранных двух-трёх источников, а не для всех.

## Что есть сейчас

Дерево root→ветви→листья→алиасы, сохранённые стадии, доказательные фильтры, осторожная
семантическая склейка, карточки и твой банковский UI. 108 тестов прошли, production build
прошёл, через API и UI проверен кеш. Пять областей дают по 15 карточек; все требуют
экспертной проверки. Инфраструктура ИИ остановлена лимитом на этапе планирования.

Не путай количество карточек с качеством: в TOP-15 у последнегоEdge лишь 2 карточки
имеют датированное раннее проявление по агентной проверке; Роботы 2, Защита ИИ 9,
Финтех 1, Индустриальный ИИ 7. Это всё равно не подтверждённая слабость рынка.
У первогоEdge132 кандидата/12 раннихпроявлений, у нового 65/2; квоты 72 против 40 и версия
планировщика различаются. Нельзя объявлять улучшение или регрессию одной правки.

Сильное возражение к нашей общей методике сохраняется: **фильтр не исключил ни одного
из трёх зрелых контролей**. Он не ломает узкие категории возрастом родителя, но положительные
доказательства массовости собирает недостаточно. Просто 0 исключений — не победа.

## Что проверить первым

1. Зафиксировать несколько пропусков Edge. Пройти hits → documents → extraction-selection
   → candidates → filters → TOP. Для каждой потери сохранить точный документ/фрагмент,
   которого не хватает. `learning/edge-reference-local-review-20260929.md` показывает
   16 границ категорий: Cortex-M не равен TDX, quantization не quantum-inspired и т.д.
2. Не ослаблять требования к цитатам ради счёта. У v3 нет полностью установленного
   совпадения по всем ограничениям в извлечённом evidence; это не отсутствие документов.
   У v1≥2 точныхмеханизма, оба сохранились после фильтров, один в TOP-15. Старые 11/16 судьи
   были мягкой иной метрикой. Проверь пересказ и извлечённый спан, а не только имя.
3. Для Kubernetes/MQTT/TLS собрать первичные доказательные досье с предметом, датами,
   регулярным применением и масштабом; затем проверить, умеет ли общий сборщик добывать
   такие досье. Не путать гарантированно зрелый широкий протокол с новой узкой реализацией.
4. После этого — Инфраструктура ИИ и последовательный 20-минутныйприёмочный прогон.
   Модельный реранкер сохранён экспериментально, не включать без человеческого контроля.
